🎮 選一個關卡開始

🦉 估價師到底在做什麼？

估價師不是賣房子的人，也不是蓋房子的人。估價師是公正的第三方，用科學的方法，找出一間房子或一塊土地「合理的價錢」。銀行要借錢給別人買房、法院要拍賣房子、政府要蓋馬路用到別人的土地、老房子要都市更新分新房子……都需要估價師來算出一個大家都能信服的數字。

估價師有三個法寶：比較法（看鄰居賣多少）、成本法（重新蓋要花多少）、收益法（租出去能收多少）。這個網站會帶你一一認識它們，還能親自上場試試看！

👩‍🏫 給老師與家長

這個網站想教什麼？

多數孩子對「房子」的理解停在「我家」和「很貴」。本站以不動產估價師的專業視角切入，讓孩子理解：價格不是隨便喊的，而是由位置、屋齡、環境、供需、法規等因素共同決定，並且可以用方法「算」出來。同時帶入都市更新、社會住宅、土地徵收、居住正義、環境風險等公共議題，培養對城市與公共事務的基本素養。

內容架構

  • 知識庫：9 個世界、122 張翻翻卡，每張都有白話解釋＋「估小泰小知識」，部分附「你知道嗎」小故事。可搜尋關鍵字。
  • 三個階層：初階（原有內容）→ 中階（集滿初階徽章解鎖：計算題、更細的案例比較、45 秒真假快答、15 秒挑戰、河岸與山城關卡、三個新任務、估價計算所）→ 進階（集滿中階徽章解鎖：兩步計算、三間排序、剔除異常案例、六選三比較標的、10 秒挑戰、大都會關卡、權變分配等任務）。中階 XP ×2、進階 ×3，解鎖中階後初階 XP 減半，等級上限 18,000 XP。
  • 稱號與認證：等級稱號（依 XP）是估小泰的成長歷程：小泰蛋 → 破殼小泰 → 學飛小泰 → 現勘小泰 → 精算小泰 → 展翅小泰 → 獵案小泰 → 明辨小泰 → 公正小泰 → 首席小泰 → 傳奇小泰，刻意不使用「估價師」這個需國家考試的法定職稱。認證（依各階層徽章集滿）共三張：估小泰初階認證「小小估價師」、中階認證「精打細算師」、進階認證「泰精準大師」，會顯示在證書上。
  • 估價師出任務：15 個情境（初階 9、中階 3、進階 3）（銀行貸款、法院拍賣、都更權變、土地徵收、店面收益、職業道德、報告品管審查、公產審查委員、調解人），每個 5 個關鍵決定，模擬估價師的判斷。
  • 價格猜猜樂：比較法「調整」的數學練習：由案例價格反推標的價格（除法與百分比）。
  • 城市規劃師：在格子地圖上配置公園、捷運、工廠、垃圾場，體會外部效果與土地使用分區的邏輯。
  • 快問快答 / 真假快答 / 哪間比較貴 / 找鄰居 / 連連看：78 題選擇題、46 題是非題與各式小遊戲，反覆練習關鍵概念。
  • XP 等級、13 枚徽章、可列印證書：維持動機，方便老師在課堂上當作任務卡使用。

對應的學習目標（國小中高年級）

  • 社會領域：居住環境、土地利用、公共建設、公民權利義務（稅、徵收補償）、環境風險。
  • 數學領域：單位換算（坪、平方公尺）、平均數、百分比（折舊、調整率）、簡單的收益換算（租金 ÷ 收益率）。
  • 理財素養：頭期款、房貸、利率、租與買的選擇、價格與價值的差別。
  • 品格教育：專業人員的公正、獨立與責任（估價師簽證負責）。

建議使用方式

  • 單堂課（40 分鐘）：選一個世界讀知識卡（10 分） → 玩「哪間比較貴」或「城市規劃師」（15 分） → 快問快答一局（10 分） → 討論：你覺得什麼最影響房價？公園旁邊比較貴公平嗎？（5 分）
  • 兩堂課進階：第二堂用「估價師出任務」分組討論每個決定為什麼對、為什麼錯，再用「價格猜猜樂」練習百分比。
  • 延伸活動：請孩子回家問家人「我們家附近最近一間房子賣多少？」，再到內政部實價登錄網站查證，體驗比較法。
  • 分組辯論：老房子該不該都更？政府可以為了蓋捷運徵收私人土地嗎？垃圾場該蓋在哪裡？

內容說明與注意事項

  • 遊戲中的價格、折舊率、調整幅度、收益率、城市地價加減成數，皆為教學用簡化數字，用來說明「方向」與「邏輯」，並非真實市場行情，也不能作為任何估價或投資依據。
  • 真實估價須依《不動產估價技術規則》進行，並由領有證照的不動產估價師簽證負責。
  • 帳號與跨裝置同步：第一次進站會自動建立一個「訪客-1234」帳號並記在這台裝置，進度與答題紀錄從第一題起就同步到雲端（Supabase）。按右上角的訪客名字，用暱稱＋密碼把訪客升級成正式帳號後，在別的電腦、平板或手機登入同一個暱稱即可接續，進度不會丟。暱稱可用中文，不需要 email；忘記密碼無法自行找回，老師可在管理後台協助重設。
  • 答題紀錄：每答一題（快問快答、真假快答、哪間比較貴、價格猜猜樂、找鄰居、城市規劃師、估價師出任務）都會記錄題目、孩子的作答、正解與時間，登入後同步到雲端。用孩子的暱稱與密碼登入「📒 紀錄」頁，可看各遊戲與各世界正確率、錯題清單、時間軸，並匯出 CSV 帶回班上討論。
  • 防連點：每一題出現後有一小段「看題時間」（基礎題約 1 秒、比較題約 2 到 3 秒、計算題 3 到 4 秒），進度條跑完才能作答；計算題答錯要先看 3 秒算法才能到下一題，連錯三題會停 8 秒並提醒拿紙筆。每題的作答秒數會記在紀錄裡，後台看得到。
  • 學校共用電腦：下課前請同學按「登出並清除這台的進度」，下一位同學才不會接到別人的進度。沒登入的同學可在徽章頁按「重新開始」清除。
  • 雲端只儲存暱稱、遊戲進度（XP、已讀卡片、徽章、各遊戲最佳成績）與答題紀錄（題目、作答、對錯、時間），不收集任何個人資料。
