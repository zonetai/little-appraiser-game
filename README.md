# 小小估價師大冒險｜不動產知識庫遊戲

給國小中高年級學生的不動產知識庫遊戲網站，以**不動產估價師**的專業視角設計。

🌐 線上遊玩：https://zonetai.github.io/little-appraiser-game/

## 內容
- 📚 9 個世界、122 張知識翻翻卡（認識不動產、房子為什麼有價錢、估價師的工作、城市與社會議題、買房租房與錢、土地環境與未來、真實工作現場、估價計算教室、世界的房子）
- 🪜 三個階層：初階 → 中階 → 進階（集滿前一階徽章解鎖），等級至 18,000 XP
- 🎮 9 個遊戲：估價師出任務（15 個情境）、估價計算所（中階以上）、快問快答（練習／挑戰）、哪間比較貴、價格猜猜樂、城市規劃師、真假快答、找鄰居（比較法）、名詞連連看
- 🏅 11 級估咕成長稱號（估咕蛋 → 傳奇估咕）、33 枚徽章、三張估咕認證（小小估價師／精打細算師／泰精準大師）、可列印證書
- ☁️ 暱稱＋密碼帳號，跨裝置同步進度（Supabase）
- 👩‍🏫 老師家長頁：學習目標對應、教案建議

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 版面與靜態頁面（首頁、老師家長、關於） |
| `style.css` | 樣式 |
| `data.js` | 全部內容：知識卡、題庫、是非題、配對、任務、關卡、徽章 |
| `app.js` | 遊戲引擎、XP／徽章、各遊戲邏輯 |
| `tiers.js` | 階層制（初階／中階／進階）：解鎖、XP 倍率、各遊戲難度模式、估價計算所 |
| `cloud.js` | 帳號與雲端同步（透過 Supabase 資料庫函式） |
| `admin.html`、`admin.js` | 管理後台（需管理帳號密碼）：帳號總覽、每日活躍、各遊戲與各世界正確率、錯題排行、單一帳號紀錄、重設密碼、CSV 匯出 |
| `assets/` | 吉祥物「估咕貓頭鷹」圖像與 22 張情境貼圖、favicon（專有素材，保留所有權利） |

純靜態網站，不需建置工具；修改內容只需編輯 `data.js`。
